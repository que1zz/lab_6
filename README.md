# Домашнее задание к работе 2

## Условие задачи

Написать программу, которая для введённого года определяет количество дней в нём.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Задать исходные данные:
  - `x` — год, введённый пользователем.
3. Проверить, является ли год високосным:
  - год високосный, если он кратен 4 и не кратен 100, либо кратен 400:
  - `(x % 4 == 0 && x % 100 != 0) || x % 400 == 0`
4. Если условие выполнено:
  - вывести сообщение «В этом году 366 дней».
5. Если условие не выполнено:
  - вывести сообщение «В этом году 365 дней».
6. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main() {
	setlocale(LC_ALL, "RUS");

	int x;
	printf("Введите год:\n");
	scanf("%d", &x);

	if ((x % 4 == 0 && x % 100 != 0) || x % 400 == 0) {
		printf("В этом году 366 дней\n");
	}
	else {
		printf("В этом году 365 дней\n");
	}
	return 0;
}
```
