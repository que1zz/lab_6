# Домашнее задание к работе 6

## Условие задачи

Для варианта 14 приведён рисунок с заштрихованной областью. Написать программу, которая:

1. считывает с клавиатуры координаты точки `x` и `y`;
2. определяет, принадлежит ли точка заштрихованной области;
3. выводит соответствующее сообщение.

Область (вариант 14) расположена:

- внутри окружности с центром в начале координат и радиусом 6: `x² + y² = 36` (граница включается);
- вне окружности с центром в начале координат и радиусом 4: `x² + y² = 16` (граница включается);
- выше прямой `y = 2` (граница включается).

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Задать исходные данные:
  - `x` — абсцисса точки;
  - `y` — ордината точки.
3. Проверить, лежит ли точка внутри большой окружности радиусом 6:
  - `x * x + y * y <= 36`;
  - если не выполнено, перейти к шагу 7.
4. Проверить, что точка не лежит внутри малой окружности радиусом 4:
  - `x * x + y * y >= 16`;
  - если не выполнено, перейти к шагу 7.
5. Проверить, что точка лежит не ниже прямой `y = 2`:
  - `y >= 2`;
  - если не выполнено, перейти к шагу 7.
6. Вывести сообщение «Точка принадлежит области» и перейти к шагу 8.
7. Вывести сообщение «Точка не принадлежит области».
8. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    double x, y;

    printf("Введите координату x: ");
    scanf("%lf", &x);
    printf("Введите координату y: ");
    scanf("%lf", &y);

    if (x * x + y * y <= 36 && !(x * x + y * y < 16) && y >= 2) {
        printf("Точка принадлежит области\n");
    }
    else {
        printf("Точка не принадлежит области\n");
    }

    return 0;
}
```
